# 카메라는 앞줄이 길면 종료된다

**증상** — 확장이 열리자마자 죽었다. 크래시 로그는 카메라를 가리켰다.

**원인** — 문서가 말한다 — **뷰파인더를 늦게 세우면 시스템이 확장을 종료한다.**
우리는 카메라 앞에 글꼴 로딩·키체인 조회·마이크 권한 요청을 두고 있었다.

**대응** — 카메라 세션을 맨 앞으로 당기고 나머지를 뒤로 미뤘다. 함께 고친 것:

- `try?`가 입력 실패를 삼켜 **입력 없이 도는 세션**이 됐다 → 오류를 실제로 다룬다
- 인쇄면 렌더가 `@MainActor`라 카메라와 같은 액터에서 그려졌다 → 그리기만 밖으로
- 오디오를 든 채 정지하면 `0xDEAD10CC` → 녹화 중에만 물게

**재발 방지** — 확장의 시작 경로에 무엇이 있는지 센다. 카메라·마이크 같은 **시스템이
기다려주지 않는 자원**은 맨 앞에 둔다.
