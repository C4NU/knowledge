# 계측이 증거를 지우고 죽음을 앞당긴다

**증상** — 크래시를 재려고 계측을 붙였더니 **계측 자체가 문제의 절반**이 됐다.
확장 크래시 여섯 중 셋이 계측 코드에서 나왔다.

**원인** — 셋 다 다른 방식이었다.

| 무엇 | 뿌리 |
|---|---|
| 죽음을 앞당겼다 | `trace()`가 호출마다 JSON을 통째로 다시 썼다 |
| 증거를 지웠다 ① | 이어받기가 원장을 덮어썼다 |
| 증거를 지웠다 ② | 성공한 판이 죽은 판의 로그를 덮어썼다 (폴더가 판마다 달랐다) |

**대응** — JSON 재작성을 텍스트 이어 붙이기로 바꾸고, 로그 폴더를 판마다 분리했다.

**재발 방지** — 계측을 붙일 때 세 가지를 확인한다.

1. **쓰기 비용** — 매 호출마다 전체를 다시 쓰지 않는가
2. **덮어쓰기** — 다음 실행이 이전 증거를 지우지 않는가
3. **가둔다** — 계측은 **가두는 것**이지 걷어내는 것이 아니다.
   조사가 끝나면 지우지 말고 플래그 뒤에 둔다

🔴 재현이 하루에 한 번뿐이면 그것부터 줄인다. 「밤을 흉내 내기」 디버그 버튼으로
하루를 몇 초로 줄였다. 단 **동시에 던지는 것**이 핵심이다 —
순서대로 부르면 고쳐지기 전에도 통과한다.
